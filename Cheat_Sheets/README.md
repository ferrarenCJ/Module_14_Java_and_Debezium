# Module 14 Cheat Sheets

## Overview

This folder contains quick-reference cheat sheets created throughout **Module 14: Java and Debezium**. These documents summarize the key concepts, commands, syntax, architectures, and troubleshooting techniques covered in the module.

The cheat sheets are intended to serve as a study guide and future reference for Java development, Spring Boot applications, Docker containerization, Change Data Capture (CDC), and Debezium.

- Docker networking allows container communication.

- CDC is a core pattern used throughout modern data engineering platforms.
