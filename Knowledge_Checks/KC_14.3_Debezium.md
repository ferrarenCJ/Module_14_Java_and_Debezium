# Question 1

## Question

What is Debezium?

## Correct Answer

```text
Debezium is an open-source distributed platform for CDC.
```

## Explanation

Debezium is a Change Data Capture (CDC) platform that monitors database changes and streams those changes to applications and downstream systems.

# Question 3

## Question

How can two Docker containers running on the same host machine see each other?

## Correct Answer

```text
By creating a Docker network and adding both containers to it.
```

## Explanation

Docker containers communicate through shared Docker networks.

Example:

```bash
docker network create myCDCNetwork
```

# Question 4

## Correct Answer


## Explanation

Docker network creation syntax:

# Question 5

## Question

Which of the following can be used to create a Docker image?

## Correct Answer

```text
Docker file
```

## Explanation

A Docker image is built using a Dockerfile.

Example:

```dockerfile
FROM mysql:8.0

EXPOSE 3306
```

Build command:

```bash
docker build -t myimage .
```
