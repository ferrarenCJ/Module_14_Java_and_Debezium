# Question 1

### Which of the programming languages below is more structured?

✅ Answer: **Java**

### Explanation

Java is a statically typed, class-based, object-oriented programming language with stricter structure requirements than Python or SQL.

# Question 4

### Which of the following is correct about file names in Java?

✅ Answer:

**The file name has to match the class name.**

### Explanation

If a Java class is public, the filename must exactly match the class name.

Example:

```java
public class HelloWorld
```

File:

```text
HelloWorld.java
```

# Question 5

### Which of the following is the basic input/output package in Java?

✅ Answer:

```java
java.io
```

### Explanation

The `java.io` package provides input and output functionality for files, streams, readers, and writers.

# Question 6

### Which command would you use to compile a Java program called hello_world.java?

✅ Answer:

```bash
javac hello_world.java
```

### Explanation

`javac` is the Java compiler that converts source code into bytecode.

Output:

```text
hello_world.class
```

# Question 7

### Which of the following files will be created after compiling a Java program called hello_world.java?

✅ Answer:

```text
hello_world.class
```

### Explanation

The Java compiler creates a `.class` file containing Java bytecode.

# Question 8

### What is the command used to print or output the string text to the console in Java?

✅ Answer:

```java
System.out.println("text");
```

### Explanation

`System.out.println()` prints text to standard output and moves the cursor to the next line.

---

# Question 9

### What is an object in Java?

✅ Answer:

**An object is an instance of the class variable.**

### Explanation

An object represents a specific instance created from a class blueprint.

Example:

```java
Car myCar = new Car();
```

- Class = Car
- Object = myCar

---

# Question 10

### What is casting in Java?

✅ Answer:

**Casting is changing the data type of a variable from one type to another.**

### Explanation

Casting converts values between different data types.

Example:

```java
String value = "12";

int number = Integer.valueOf(value);
```

---

# Question 11

### Which of the following statements is true about packages?

✅ Answer:

**Packages allow a programmer to instantiate classes into objects within other classes.**

### Explanation

Packages organize related classes and allow those classes to be imported and used throughout an application.

Example:

```java
import java.util.Scanner;
```

After importing, objects can be created from classes located in the package.
