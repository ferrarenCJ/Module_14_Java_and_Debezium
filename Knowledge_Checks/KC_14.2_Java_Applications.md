# Question 1

## Question

What is the correct syntax to copy a file from the host to a container?

## Correct Answer

```bash
docker cp hello.txt container1:/hello.txt
```

## Explanation

The `docker cp` command copies files between a host machine and a Docker container.

General syntax:

```bash
docker cp <source> <container>:<destination>
```

# Question 4

## Question

What is Change Data Capture (CDC)?

## Correct Answer

```text
CDC is a process that captures changes made in a database and replicates those changes to destination(s).
```

## Explanation

CDC monitors:

```text
INSERT
UPDATE
DELETE
```

operations and propagates those changes to downstream systems.

# Question 5

## Question

What is the advantage of using periodic queries to capture changes in a database?

## Correct Answer

```text
Periodic queries have low overhead on well-indexed databases.
```

## Explanation

Periodic polling can be efficient when databases are properly indexed and change volumes are moderate.

# Question 6

## Question

What is the disadvantage of using transaction log processing for CDC?

## Correct Answer

```text
Transaction log processing is hard to implement for every database vendor.
```

## Explanation

Each database vendor maintains different transaction logs and APIs, making CDC implementations more complex.

Examples:

```text
MySQL Binlog
PostgreSQL WAL
SQL Server Transaction Log
```

# Question 9

## Question

Which Python library is used to perform CDC using a Python program?

## Correct Answer

```text
pymysqlreplication
```

## Explanation

The `pymysqlreplication` library reads MySQL binary logs and enables Python applications to capture database changes in near real-time.
