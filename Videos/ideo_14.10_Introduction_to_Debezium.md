**Duration:** 3:55

# Overview

Module 14 introduces the Java programming language and Debezium, an open-source Change Data Capture (CDC) platform. The module combines software development concepts with modern data engineering practices by exploring Java application development, Spring Boot, containerization, event-driven architectures, and CDC pipelines.

The module progresses from Java fundamentals to building applications and ultimately implementing CDC using Debezium and Docker.

---

# Learning Objectives

By the end of this module, students will be able to:

1. Define elements of the Java programming language.
2. Write basic Java code.
3. Compare and contrast Java and Python.
4. Upload and download files to and from containers.
5. Develop a web application in Java.
6. Identify key characteristics of Java applications.
7. Set up a Docker network for Debezium.
8. Connect a database to Debezium.
9. Identify key elements of Debezium.

# Why Java Matters in Data Engineering

Many Apache Software Foundation projects are either written in Java or rely on the Java ecosystem.

Examples include:

- Apache Kafka
- Apache Hadoop
- Apache Spark
- Apache Flink
- Apache Beam

Because of its scalability and performance, Java remains one of the most widely used programming languages for:

- Enterprise applications
- Distributed systems
- Big data platforms
- Stream processing
- Backend development

# Java vs Python

## Java

### Advantages

- Strongly typed language
- High performance
- Excellent scalability
- Large enterprise adoption
- Robust tooling and frameworks

### Common Uses

- Enterprise software
- Backend microservices
- Big data frameworks
- Distributed systems

---

## Python

### Advantages

- Easy to learn
- Rapid development
- Extensive data science libraries
- Excellent readability

### Common Uses

- Data analysis
- Machine learning
- Data engineering pipelines
- Automation scripts
