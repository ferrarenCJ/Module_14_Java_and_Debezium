# Overview

Module 14 introduces the Java programming language and Debezium, an open-source Change Data Capture (CDC) platform. The module combines software development concepts with modern data engineering practices by exploring Java application development, Spring Boot, containerization, event-driven architectures, and CDC pipelines.

The module progresses from Java fundamentals to building applications and ultimately implementing CDC using Debezium and Docker.

# Why Java Matters in Data Engineering

Many Apache Software Foundation projects are either written in Java or rely on the Java ecosystem.

Examples include:

- Apache Kafka
- Apache Hadoop
- Apache Spark
- Apache Flink
- Apache Beam

Because of its scalability and performance, Java remains one of the most widely used programming languages for:

- Enterprise applications
- Distributed systems
- Big data platforms
- Stream processing
- Backend development

# Key Terms

## Java

An object-oriented programming language widely used in enterprise and big data environments.

## Class

A blueprint used to create objects.

## Object

An instance of a class.

## Package

A collection of related Java classes and interfaces.

## Container

An isolated environment used to run applications and services.

## CDC (Change Data Capture)

A technique used to identify and capture database changes as they occur.

## Debezium

An open-source CDC platform that captures database changes and streams them to downstream systems.

## Spring Boot

A Java framework used to develop web applications and microservices.

## Event-Driven Architecture

A system design approach that reacts to events such as data creation, updates, or deletions.
